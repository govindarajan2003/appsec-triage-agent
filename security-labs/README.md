# Security Labs

A personal security learning notebook. Each subdirectory documents one vulnerability class with:

* `THEORY.md` — What the vulnerability is and why it happens
* `EXPLOIT.md` — How I manually reproduced it in my lab
* `REMEDIATION.md` — The fix and why it works
* `SCANNER-RESULTS.md` — What scanners detected (and missed)
* `REGRESSION-TESTS` — Automated tests proving the fix

> This notebook exists as a personal documentary of my learning journey.
