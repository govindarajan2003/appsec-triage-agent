# Appsec Triage Agent

An AI-assisted application security platform that orchestrates multiple security-scanners (SAST, SCA, Secret scanning), normalizes their findings, correlates related evidence, and uses a LangGraph-based agent to investigate vulnerabilities with code context, historical data, and security knowledge.

The platform demonstrates both building agentic AI Systems and defending them against prompt injection and unsafe tool execution.

## About This Project

This is a deliberate learning project. I'm building it to understand application security deeply while creating a portfolio piece that sits at intersection of AI Engineering and AppSec. The vulnerable demo application, security-labs notebook, and architecture decision log document the learning process openly.
